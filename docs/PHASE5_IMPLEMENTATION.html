1. Data Classes

SupplierFact.java

Purpose: Represents one extracted fact from a document
@Data public class SupplierFact { private String category; // "employees", "revenue", etc. private String value; // "1,250 employees" private Double confidence; // 0.0-1.0 confidence level private List<Integer> pages; // [3, 5] where found private String reasoning; // Why extracted }

Purpose: All facts extracted from one document (JSON response from LLM)

Purpose: One chunk of text extracted from a PDF page
@Data @AllArgsConstructor public class PageChunk { private Integer pageNumber; // 1-indexed page private String text; // 500-char text chunk private Integer startPosition; // Char position private Integer endPosition; // Char position }

2. Entity & Repository

ExtractionResult.java

Purpose: Immutable database record of one extraction (audit trail)
@Entity @Table(name = "extraction_results") public class ExtractionResult { @Id private UUID id; @ManyToOne @JoinColumn(name = "case_id") private DueDiligenceCase caseEntity; @ManyToOne @JoinColumn(name = "document_id") private Document documentEntity; private String toolName; // "DOCUMENT_EXTRACTION" private String toolType; // "EVIDENCE_EXTRACTION" private String input; // JSON input private String output; // JSON facts private Boolean success; // true/false private String errorMessage; // If failed private String evidence; // Human-readable private String promptVersion; // "v1", "v2", etc. private String modelUsed; // "gpt-4-turbo" private Integer tokensUsed; // Cost tracking private LocalDateTime executedAt; // Immutable }

Purpose: Database queries for ExtractionResult
@Repository public interface ExtractionResultRepository extends JpaRepository<ExtractionResult, UUID> { @Query("SELECT e FROM ExtractionResult e WHERE e.documentEntity.id = :documentId") List<ExtractionResult> findByDocumentId(UUID documentId); @Query("SELECT e FROM ExtractionResult e WHERE e.caseEntity.id = :caseId AND e.success = :success") List<ExtractionResult> findByCaseIdAndSuccess(UUID caseId, Boolean success); @Query("SELECT e FROM ExtractionResult e WHERE e.caseEntity.id = :caseId") List<ExtractionResult> findByCaseId(UUID caseId); List<ExtractionResult> findByPromptVersion(String promptVersion); List<ExtractionResult> findByModelUsed(String modelUsed); }

3. Services

DocumentParser.java

Purpose: Extract text from PDF and break into chunks Key Method: parseDocument(File pdfFile): List<PageChunk>
1. Load PDF using Apache PDFBox 2. Extract text page-by-page 3. Split into 500-char chunks 4. Add 50-char overlap between chunks 5. Track page numbers for citations 6. Return List<PageChunk> with all metadata

DocumentEvidenceAgent.java

Purpose: Orchestrate entire extraction workflow Key Method: extractSupplierEvidence(UUID caseId, UUID docId, File file): ExtractionResult
1. Parse PDF using DocumentParser → List<PageChunk> 2. Load prompt from supplier_extraction_v1.txt 3. Call LLM with document chunks (OpenAI when Spring AI ready) 4. Parse JSON response → SupplierFactsOutput 5. Build evidence string with confidence scores 6. Create ExtractionResult record 7. Save to extraction_results table 8. Return result (HTTP 200 always, errors as data)

📝 LLM Prompt Template

File: supplier_extraction_v1.txt
Purpose: Instructions for LLM on what to extract and how to score confidence

Key Sections:
  • Facts to extract: 10 categories (employees, revenue, locations, certifications, regulatory_status, red_flags, ownership, years_in_business, industry, financial_health)
  • Confidence scoring: 1.0 (explicit) → 0.85 (implied) → 0.70 (inferred) → 0.50 (ambiguous)
  • Page references: Track which pages each fact appears on
  • Constraints: No assumptions, no marketing claims, require currency/period, track page numbers
  • Output format: Strict JSON with facts[], summary, complete boolean

🔄 Complete Workflow (11 Steps)

1. User uploads PDF document ↓ 2. POST /api/cases/{caseId}/documents/{docId}/extract-evidence ↓ 3. DocumentEvidenceController validates case & document exist ↓ 4. DocumentParser.parseDocument(file) → Apache PDFBox opens PDF → Extracts text page-by-page → Creates 50 PageChunks (500 chars + 50-char overlap) ↓ 5. DocumentEvidenceAgent.extractSupplierEvidence() ↓ 6. Load supplier_extraction_v1.txt prompt template ↓ 7. Call LLM (OpenAI GPT-4-Turbo when Spring AI 2.0+ ready) → Send: system prompt + document chunks → Return: Structured JSON with facts ↓ 8. Parse JSON response → SupplierFactsOutput → Extract 5-10 facts with confidence (0.5-1.0) → Track page citations ↓ 9. Build evidence string (human-readable summary) ↓ 10. Create & save ExtractionResult → Store input, output, metadata → HTTP 200 OK (always, errors as data) ↓ 11. Facts available for: → Phase 6: Governance checks → Phase 7+: RAG system → Human review interface
