Levenshtein Distance Algorithm

Fuzzy name matching handles company name variations:

Example: "Acme Corp" vs "Acme Corporation Pty Ltd"

Step 1: Normalize
  "acme corp" vs "acme corporation pty ltd"

Step 2: Contains check
  "acme corp" is substring of "acme corporation pty ltd"
  → Match at 95% similarity ✓

Step 3: Levenshtein distance (fallback)
  Calculate minimum edit operations needed
  similarity = 1.0 - (distance / maxLength)
  Match if similarity > 80% threshold

Matching Logic Priority:

  1. Exact match → 1.0 (100%)
  2. Contains match → 0.95 (95%)
  3. Levenshtein distance → calculated (must be > 80%)
  4. No match → similarity score stored for investigation

Error Handling

Scenario: API Timeout

ABNLookupService.lookupABN("12345678901")
  → RestTemplate timeout (5 seconds)
  → Catch RestClientException
  → Throw RuntimeException("Failed to lookup ABN: ...")

SupplierVerificationService.verifySupplier()
  → Catch RuntimeException
  → Log: "Supplier verification failed for case ..."
  → Save ToolResult(success=false, errorMessage="...")
  → Return failed result (no exception bubbles)

Scenario: Invalid ABN

Input: "123" (not 11 digits)
  → ABNLookupService validates: !abn.matches("\\d{11}")
  → Throw RuntimeException("ABN must be 11 digits")
  → Caught by verifySupplier, saved as failed result

Key Learnings

1. Tool Calling Pattern

How do agents invoke external services? Tool abstraction layer (ABNLookupService) that agents will call in Phases 5-10.

2. External API Integration

Timeouts: RestTemplate configured with 5-second limits prevents hanging

Validation: ABN format checked before API call (fail-fast)

Error Resilience: All failures caught, logged, and persisted

3. Fuzzy Matching

Levenshtein distance + contains logic handles name variations. 80% threshold balances false positives vs false negatives.

4. Immutable Evidence Trail

ToolResult is write-once, never updated. Complete audit trail; agents can't retroactively change findings.

5. Structured JSON for Tool I/O

Input/output stored as JSON. Future phases parse and reason about tool results. JSON accommodates different tool structures.
